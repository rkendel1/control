## Executive summary

The inventory covers every tracked and non-ignored file currently present. The
packaged desktop has one production UI graph rooted at `src-ui/main.tsx` and
one native entrypoint rooted at `src-tauri/src/main.rs`. FeltDB is the durable
authority for the Control work graph. The filesystem, Git, OS keychain, native
process supervisor, and React own only their documented domains.

The audit found and removed the complete superseded Mission Control Next.js/JSON
application, daemon, older browser graph/conversation implementation,
feature-gated native JSON state, obsolete IPC, stale agent tooling, and historical
documentation. The remaining inventory has zero legacy, dead, unknown, or
deletion dispositions.

## Canonical architecture

| Responsibility | Authority |
|---|---|
| Work, Task, Conversation, Run, Run event, Inbox, Decision, Evidence, Outcome | FeltDB |
| Source files | Workspace filesystem |
| Version history and repository state | Git |
| Credentials | OS keychain |
| Live process and PTY state | Native supervisor and operating system |
| Ephemeral presentation state | React |

Production flow:

```text
main.tsx → bootstrap.tsx → Workbench / CoordinationPanel → typed Tauri IPC
             → commands.rs → native filesystem/Git/PTY/runtime services
             → FeltDB for the canonical durable Work graph
```

## Resolved duplicate and legacy findings

1. Removed the separate Next.js UI, JSON source of truth, API routes, daemon,
   execution paths, field operations, and their tests/assets.
2. Removed the unreachable browser graph, conversation-provider, persistence,
   resilience, safety, demo, and placeholder UI stacks.
3. Removed `legacy-native-state`, JSON-backed domain modules, compatibility
   handlers, and seven unused registered IPC commands. All 41 remaining native
   commands are defined, registered, and called by production UI code.
4. Removed or rewrote historical documents, agent commands, skills, launchers,
   scripts, ignore rules, and dependencies that referenced the old architecture.
5. Standardized JavaScript tooling on npm and one lockfile. Removed unused Rust
   dependencies and retained only canonical native platform services.
6. Replaced Windows startup and CI behavior with direct Tauri desktop workflows;
   CI now declares macOS, Ubuntu, and Windows verification jobs.

external-service, and JSON mutation paths have been removed rather than retained
